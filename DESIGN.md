# Showcase design

<!-- impeccable:design-schema 1 -->

The showcase is a simple gallery of the actual RPG icons. A compact header, short introduction, search and filters, and an enlarged preview make the results easy to browse.

Use a flat dark forest background (#141a16), muted green surfaces (#1d2520), readable cream text (#eee9dc), and a quiet brass accent (#d0b582). System sans-serif keeps the interface legible; a modest Georgia heading gives a subtle RPG tone.

Keep spacing consistent and decoration minimal. Avoid hero illustrations, textures, marketing claims, statistic banners, process panels, and prompt sections. Prompts and instructions stay in SKILL.md.

The gallery has a preview rail on desktop and a preview below the icons on mobile. Buttons have visible focus and selected states. Preview images use integer scaling and pixelated rendering. Download links refer directly to the exported PNGs.
