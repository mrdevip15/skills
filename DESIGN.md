# Visual direction

<!-- impeccable:design-schema 1 -->

## World

The showcase is a field guide from a retro RPG guild: a crafted archive where icons feel like collected artifacts and the production details read like a quest log. The artifact leads, while the interface gives creators enough structure to reuse the recipe.

## Surface strategy

The first viewport opens with one clear promise and a visible stack of real icons. The visitor moves through the catalog, selects an artifact, copies a prompt recipe, then opens the workflow and validation layers when they need proof. The page uses a broken editorial grid with a wide catalog and a narrow inspector rail.

## Palette

- Ink pine: `#101612` and `#17211b` for the world surface.
- Aged parchment: `#f0e4c7` for primary text and light inspection stages.
- Moss gray: `#9ba99b` for supporting copy and metadata.
- Ember: `#d97a45` for one active action color and selected states.
- Brass: `#c9a967` for quiet labels and the archive seal.

## Typography

Use `DM Sans` for reading and controls, `Cormorant Garamond` for the display title and section markers, and `DM Mono` for coordinates, counts, and code. Headings are sentence case with generous display scale. Numbers use tabular figures.

## Materials and details

Use fine ruled lines, subtle paper grain, archival labels, inset frames, and offset blocks. Keep corners mostly square with one or two softened containers so the page feels like a printed field guide assembled on a game UI. Motion is short and tactile: icons lift slightly, drawers reveal, and sections fade upward. Respect reduced motion.

## Interaction rules

The catalog is the primary action. Every filter is a real button with a visible focus state. The selected icon stays visible in the inspector while browsing. Prompt copy gives immediate feedback. The page remains useful at small widths by moving the inspector below the grid and keeping controls horizontally scrollable.
