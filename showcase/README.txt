Infinity Forest Icon Pack
=========================

Contents:
- 88 sliced PNG icons
- 32x32 px: skills, resources, status, boons, stats
- 48x48 px: evolution paths, titles, difficulty
- Transparent RGBA PNG
- Sliced from the generated atlases using the included JSON manifest
- Resized using nearest-neighbor

Folder structure:
asset/icons/skills/
asset/icons/resources/
asset/icons/status/
asset/icons/boons/
asset/icons/stats/
asset/icons/paths/
asset/icons/titles/
asset/icons/difficulty/

icon_grid_manifest.json contains the original atlas coordinates.
