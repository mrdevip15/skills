The spellbook

Give ChatGPT a world it can keep coherent.

Start with a style anchor, define the grid, then describe what must stay stable. This is the small brief behind the pack.

MASTER PROMPT / ICON SET
Create a cohesive RPG icon set for a dark forest kingdom.
Use crisp 16-bit pixel art, hard-edged pixels, no anti-aliasing,
a limited palette, one-pixel dark outline, and top-left lighting.
Keep one centered symbol per square tile, generous internal padding,
and a consistent visual weight across the whole set.
Output transparent PNGs at the requested size. Avoid text and logos.
01 / Style anchorPalette, light, outline, era.
02 / Grid contractCell size, margins, no bleed.
03 / Export rulesRGBA, nearest neighbor, named paths.

    01
    Count parity
    Requested icons, manifest entries, and exported files match at 88 of 88.
    
        
    02
    Two clear scales
    Gameplay icons land at 32 × 32. Paths, titles, and difficulty emblems land at 48 × 48.
    
        
    03
    Nearest neighbor
    Hard pixel edges survive the resize with no soft interpolation or fuzzy halos.
    
        
    04
    True transparency
    RGBA output keeps the icons ready for compositing over any game surface.
    
        
    05
    Safe namespaces
    Shared names such as guard and focus stay separate inside their category folders.
    
        
    06
    Drop-in structure
    The archive preserves asset folders, the manifest, and the README beside the icons.

    // Programmatic slicing and resizing
const sharp = require('sharp');
const manifest = require('./icon_grid_manifest.json');

for (const [sheetKey, sheet] of Object.entries(manifest.sheets)) {
  for (const icon of sheet.icons) {
    await sharp(sheet.source)
      .extract({ left: icon.x, top: icon.y, width: icon.width, height: icon.height })
      .resize(sheet.final_icon_size, sheet.final_icon_size, {
        kernel: sharp.kernel.nearest
      })
      .png()
      .toFile(icon.output);
  }
}
